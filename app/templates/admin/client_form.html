Guia: Como criar a Role na conta do cliente

O cliente precisa criar uma Role IAM que permita que sua conta AWS assuma temporariamente.

1. Crie a Trust Policy (substitua SEU_ACCOUNT_ID):

{ "Version": "2012-10-17", "Statement": [{ "Effect": "Allow", "Principal": { "AWS": "arn:aws:iam::SEU_ACCOUNT_ID:root" }, "Action": "sts:AssumeRole", "Condition": {} }] }

2. Políticas recomendadas (somente leitura):

  • ReadOnlyAccess (AWS Managed)
  • SecurityAudit (AWS Managed)
  • AWSCostAndUsageReportAutomationPolicy
  • Cost Explorer: ce:* (leitura)
  • Compute Optimizer: compute-optimizer:* (leitura)

3. AWS CLI (na conta do cliente):

aws iam create-role \ --role-name FinOpsAnalyzerRole \ --assume-role-policy-document file://trust-policy.json aws iam attach-role-policy \ --role-name FinOpsAnalyzerRole \ --policy-arn arn:aws:iam::aws:policy/ReadOnlyAccess aws iam attach-role-policy \ --role-name FinOpsAnalyzerRole \ --policy-arn arn:aws:iam::aws:policy/SecurityAudit
